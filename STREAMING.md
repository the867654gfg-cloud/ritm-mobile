# Адаптивное аудио Ритма

Команда для опубликованного трека Ритма, на который у проекта есть исходный файл и право на повторное кодирование:

```sh
node scripts/package-audio.mjs TRACK_ID SOURCE_FILE MEDIA_DIRECTORY
```

Нужен FFmpeg с поддержкой AAC и HLS. Переменная `RITM_FFMPEG` позволяет указать путь к бинарнику. Для проверенного lossless-исходника (например, PCM WAV или FLAC) добавьте `--lossless`. Уже сжатый с потерями исходник нельзя восстановить конвертацией во FLAC.

В каталоге `MEDIA_DIRECTORY/TRACK_ID` появятся главный `index.m3u8`, плейлисты и сегменты AAC 96, 160 и 320 кбит/с по четыре секунды, а также три полных M4A для скачивания. С флагом `--lossless` появятся ещё FLAC-вариант в fMP4 и отдельный файл `lossless.flac`.

Публикуйте сегменты, дочерние плейлисты и M4A/FLAC первыми, главный `index.m3u8` последним. Хост должен раздавать их по HTTPS и разрешать CORS для сайта Ритм. Укажите типы `application/vnd.apple.mpegurl` для плейлистов, `audio/mp4` или `video/mp4` для fMP4/M4A и `audio/flac` для FLAC. Сегменты, которые больше не изменяются по этому URL, можно кешировать длительно. Для манифестов используйте короткий кеш.

Публичный адрес `MEDIA_DIRECTORY` задаётся через `EXPO_PUBLIC_RITM_MEDIA_URL` в GitHub Actions и в окружении сборки iOS. При выключенной переменной обе версии используют аудио из исходного каталога. Подготовка выполняется только для треков из хранилища Ритма. Внешние треки продолжают играть из источника.

Браузер сохраняет новые загрузки с AES-GCM через service worker. iOS использует фоновую сессию загрузки, зашифрованный файл в контейнере приложения, Keychain и SQLite. На iOS декодер открывает временную расшифрованную копию. В обеих версиях текущий лимит одного скачивания — 32 МБ. Для проверки фоновой сессии, закрытия приложения и офлайн-режима требуется физический iPhone.

## Очередь обработки опубликованных треков

Миграция `playback_handoff_and_media_queue` ставит опубликованные исходники в очередь и добавляет отдельную позицию воспроизведения для каждого аккаунта. После применения миграции сервер с FFmpeg и Node.js запускает:

```sh
node scripts/process-audio-queue.mjs --watch
```

Укажите `RITM_SUPABASE_URL` и `RITM_SUPABASE_SERVICE_KEY` в окружении сервера. Ключ сервиса не входит в сборки сайта и iOS. Worker размещает подготовленные файлы в `music-storage/ritm-streams`. Публичный HTTPS-адрес этого префикса используйте как `EXPO_PUBLIC_RITM_MEDIA_URL` в обеих сборках. Манифест публикуется последним. Ошибку обработки владелец может повторно поставить в очередь через «Загруженные».
